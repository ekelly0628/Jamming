# 🎵 Spotify Playlist App

## 📌 Purpose

A React-based web app that allows users to search for songs and create custom playlists, which can be exported to their Spotify account.

## 🛠 Technologies Used

- React
- Spotify Web API
- OAuth 2.0
- Git & GitHub
- Vercel (Deployment)

## 🚀 Features

- Search songs by title, artist, or genre
- View song details (title, artist, album)
- Add/remove songs to/from a playlist
- Export playlist to Spotify
